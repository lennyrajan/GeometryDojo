# Geometry Dojo

A minimalist PWA game where precision is everything.

## Setup

This project uses Vite + React + TailwindCSS.

1.  **Install Node.js**: Ensure Node.js (v18+) is installed.
2.  **Install Dependencies**:
    ```bash
    npm install
    # or
    yarn
    ```
3.  **Run Development Server**:
    ```bash
    npm run dev
    ```
    Open `http://localhost:5173` on your mobile device (on the same network) to test touch capability.

## Features

- **10 Levels**: From Line to Star.
- **Precision Scoring**: 0.0 - 100.0% accuracy.
- **Heatmap**: Visual feedback on where you strayed.
- **Progression**: Unlock levels by scoring > 99.5%.
- **PWA**: Installable on mobile devices.

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Vite PWA Plugin
